# Skill V3 verbatim/selective Skill compiler strategy pivot

This directory is an offline architecture/design seal. It reconstructs the current stage-specific Skill path, evaluates complete verbatim injection first, and only then chooses a successor architecture.

`Selective Compiler` is **not** a predetermined required architecture. The priority baseline was the complete original `SKILL.md` text of every Skill selected by the existing Planning resolver. That baseline passed conservative capacity, but failed safety, repetition, and stage-ownership gates. The resulting recommendation is therefore `SELECTIVE_VERBATIM_SECTIONS_PREFERRED`, not an assumed conclusion.

No production source, prompt, route/model, retry/fallback, budget, authority, Provider, model, network, approval, nonce, Pair 2–5, or Full Short action is part of this evidence.
