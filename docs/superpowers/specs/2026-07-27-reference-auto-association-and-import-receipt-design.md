# 参考资料自动关联与导入结果单设计

## 目标

导入资料后，系统应立即说明识别结果、判断依据、可信程度、允许参与的功能、下一步操作及 Token 影响。自动化只处理证据充分且可逆的关联；写法采纳、竞品身份和可能污染作品的决定继续由用户确认。

## 分类模型

每份资料同时具有三个维度，界面不得只显示一个“内容类型”：

1. **内容类型**：参考作品、平台规则、爆款样本、写作教程、竞品作品。
2. **可信状态**：系统推测、用户确认、榜单验证。
3. **使用范围**：全局方法、指定平台、指定项目、市场样本组。

导入时保存分类快照，包括推荐平台、推荐内容类型、置信度、判定依据和选择来源。用户在导入表单中明确选择或随后保存修改时，状态为“用户确认”。爆款样本只有与本地榜单作品建立已确认关联后，才升级为“榜单验证”；仅含“爆款、高赞、热门”等文字时显示“自述爆款”，不能进入真实市场基线。

竞品作品永不自动确认。系统可以根据平台、题材、篇幅和市场样本组推荐竞品身份，但必须由用户确认。

## 自动关联

导入后继续使用现有本地榜单匹配，不调用模型：

- 唯一候选同时满足规范化标题完全一致和正文开头/榜单简介相似时，自动建立可撤销的榜单关联。
- 只有标题相似、存在同名作品或证据不足时，只显示候选，不自动关联。
- 未匹配到榜单时保留资料，不降低本地提炼能力，并明确显示“暂无市场证据”。
- 用户手动取消自动关联后，该资料不会在同一版本上再次自动关联；正文或标题产生新版本后才重新推荐。

平台规则按平台作用，不学习文风。写作教程默认进入全局方法库。参考作品按平台、长短篇、题材和目标读者向项目推荐，但不会自动采纳候选写法。竞品作品只参与差异化和原创风险比较，默认不参与文笔基线。

## 功能路由

系统根据内容类型生成“可用于什么”和“建议下一步”，不为导入动作自动调用模型：

| 类型 | 可参与功能 | 默认排除 |
|---|---|---|
| 平台规则 | 平台投稿检查、硬性规则提取 | 文风学习、爆款基线 |
| 榜单验证爆款 | 市场基线、爆款本地分析、创建向导、大纲和正文市场比较 | 自动采纳写法 |
| 自述爆款 | 爆款本地分析、结构候选 | 真实市场统计 |
| 参考作品 | 本地提炼、剧情吸引力、文笔与结构候选 | 未确认的项目采纳 |
| 竞品作品 | 原创相似度、题材重合、差异化检查 | 文笔模仿 |
| 写作教程 | 全局写作方法、适用条件和检查项 | 教程原文文风学习 |

创建向导、大纲检查、本地正文分析和终审从同一份用途路由读取资料。市场基线只提供参考区间，不成为强制模板。

## 市场样本分组与权重

市场基线继续按平台、长短篇和分类分组，并增加抓取日期信息。样本权重由本地数据确定：多日上榜、近期记录、较高排名和可用互动量提高权重；只有一天记录、数据陈旧或指标缺失降低权重。权重只影响汇总占比，不伪造样本或市场结论。

长篇和短篇不得进入同一基线。跨平台、跨题材或跨篇幅资料只作为可见参考，不影响当前项目的默认基线。

## 更新与隔离

- 修改平台：重新计算平台规则范围和市场分组。
- 修改内容类型：重新计算用途，不自动删除历史分析。
- 修改或取消榜单关联：更新市场背景及相关基线。
- 更新正文版本：本地分析和模型分析标记为需要更新；不相关采纳继续保留。
- 系统生成的项目正文不得自动成为爆款样本或市场样本。只有导入外部市场证据并经用户确认后，才允许升级。
- 已采纳写法仍按现有逻辑在来源元数据变化时标记待复核，正式正文不自动修改。

## 导入结果单

导入成功后，在资料详情顶部显示一张非模态结果单，不使用抽象内部术语：

> 系统识别：知乎短篇参考作品  
> 可信状态：系统推测（依据：网址域名、标题和正文开头）  
> 市场匹配：发现 1 个榜单候选，等待确认  
> 推荐用于：剧情结构提炼、开头吸引力分析  
> 下一步：确认榜单关联 → 本地提炼 → 查看候选写法  
> 本次导入未调用模型，不会自动修改作品

结果单必须提供与状态对应的直接操作按钮，不要求用户到其他页面寻找功能。自动关联成功时提供“查看依据”和“撤销关联”；候选匹配提供“确认关联”；无匹配时提供“稍后重新匹配”。结果单可折叠，但重新打开资料后仍能从保存的分类快照和当前关联状态重建。

## 错误与空状态

- 分类证据不足：显示“暂按参考作品保存”，不显示失败。
- 榜单为空或结构变化：不阻止 TXT 导入，结果单说明市场匹配暂不可用。
- 没有适合项目：显示“尚未找到同类项目”，不自动绑定最相近项目。
- 用户手动选择优先于系统推荐，并显示“你已确认”。
- 每个推荐说明会影响什么、不会影响什么，以及是否调用模型。

## 数据兼容

在现有 `reference_sources` 上增加一个可空的分类快照 JSON 字段，通过幂等迁移回填旧资料。旧资料默认根据现有平台、内容类型和当前榜单关联重建状态，不改变正文、版本、项目关联、学习节点或采纳记录。

## 验收标准

- 自动分类保存置信度、依据和选择来源，旧资料迁移幂等。
- 自述爆款不会进入真实市场基线；确认榜单关联后显示“榜单验证”。
- 唯一强匹配可以自动关联，歧义匹配保持待确认且可撤销。
- 五类资料得到不同的用途和下一步推荐，且导入不会调用模型。
- 市场基线严格隔离长短篇，并按历史、时效、排名和互动量计算可解释权重。
- 系统生成正文不能自动进入市场学习。
- 导入结果单在桌面和移动视口均可读，操作按钮不溢出、不重叠，状态和进度有明确反馈。
- 完整测试保持通过，现有资料、模型绑定、榜单历史和项目正文不丢失。
