# 任务式工作台、参考资料创作与草稿删除设计

## 范围

本设计与《小说安全定向返修设计》在同一轮实施。安全定向返修负责限制模型改动、执行本地验收、选择局部或全文终审并保留最佳稿；本设计负责把这些能力整理成用户容易操作的入口，并补齐从多篇参考资料创建作品和删除未完成开书草稿的能力。

本轮不新增第二套正文、候选稿、大纲或项目状态。页面继续调用现有项目、学习库、StoryState、运行任务和质量报告接口。

## 目标

- 首页只回答四件事：当前是哪部作品、进行到哪一步、最需要处理什么、现在应该点哪个按钮。
- 侧栏从八个同级入口缩减为“创作、资料与学习、市场、设置”四组，原有页面和数据仍然可以进入。
- 用户可以选择一篇或多篇参考文章，创建新作品并生成原创候选大纲。
- 用户可以删除尚未完成的开书草稿，不影响已经创建的作品。
- 所有进度、失败原因和下一步都使用容易理解的中文。

## 不做的内容

- 不删除项目资料、模型设置、写作能力、回收站、日志或高级状态页面。
- 不把参考文章原文直接交给大纲模型模仿。
- 不自动采用候选大纲，不改已有正文。
- 不在首页复制一套大纲编辑器、返修编辑器或运行日志。
- 不从“删除草稿”入口删除正文草稿、候选大纲、最佳稿、正式稿或运行历史。

## 任务式工作台

### 侧栏

侧栏只显示四个主入口：

1. 创作：当前作品、下一步、关键问题、生成与返修进度。
2. 资料与学习：项目资料、参考文章、候选写法和作品应用。
3. 市场：保留现有市场趋势与同类样本页面。
4. 设置：模型设置、写作能力和回收站。

旧的单页视图继续保留。`showView()` 增加父分组映射：打开项目资料或学习库时高亮“资料与学习”，打开新建作品时高亮“创作”，打开模型、写作能力或回收站时高亮“设置”。因此只改变导航层级，不删除旧功能。

### 首页首屏

首页首屏依次显示：

- 当前作品选择和“新建作品”。
- 当前阶段：例如“还没有正文”“正在生成”“有 3 个问题需要处理”“可以终审”“可以准备投稿”。
- 最重要的 1 至 3 个问题。问题来自现有本地分析和终审问题台账，不重新计算另一套分数。
- 一个主操作按钮。按钮文字直接说明结果，例如“继续初始化”“生成完整短篇”“修复已选问题”“继续上次任务”“准备投稿”。

主操作由当前数据确定：

1. 没有作品时进入新建作品。
2. 初始化未完成时继续初始化。
3. 有正在运行的任务时查看当前进度，不重复启动。
4. 没有正文时进入现有生成流程。
5. 有未处理问题时进入安全定向返修。
6. 终审通过后进入发布准备。

首页不自行改稿，也不绕过现有权限检查。它只把用户的操作转到现有工作流或本轮新增的安全返修接口。

### 详细内容

文件位置、完整评分依据、全文、保护片段、写作规则、发布设置、运行日志和作品列表仍在工作台，但默认折叠到“查看详细信息”。正在运行或失败的任务状态始终可见，不能藏在折叠区。

移动端保持单列。主按钮、作品选择和当前进度不能随动态文字改变尺寸；长错误信息换行，不能覆盖后续内容。

## 从所选参考文章创建作品

### 选择

参考资料列表增加稳定的多选控件和选择状态栏。用户可以勾选一篇或多篇资料，再点击“用所选资料创建新作品”。单篇详情中的“从此资料创建作品”继续保留，走同一函数。

平台规则、写作教程等资料可以留在学习库，但这个入口只接受参考作品和爆款样本；竞品禁用资料不能进入创作上下文。

### 准备学习成果

系统逐篇检查是否已经完成本地提炼：

- 未提炼的资料先执行现有本地提炼，不调用模型。
- 每篇资料至少需要一条用户已确认的候选写法。
- 如果存在尚未确认的资料，页面保留已选择项目并转到“候选写法”，明确告诉用户还需要确认哪几篇。
- 一次最多带入 12 条已确认写法；超过时在向导确认页让用户选择，不静默丢弃。

API 校验允许选择任意有效的已确认写法，不再错误地只接受全局列表最前面的 12 条。从所选资料创建时，向导只列出这些资料的全部已确认写法，并使用折叠分组避免页面过长；用户最多勾选 12 条。普通自主创建仍只推荐全局列表前 12 条。

### 创建与生成候选大纲

前端继续复用现有向导和学习库接口：

1. 创建开书向导。
2. 将所选资料的“可迁移写法”和来源名称写入向导建议，不写入来源原文。
3. 用户补充新故事的标题、创意、人物和篇幅。
4. 用户确认后创建项目，并将勾选写法采纳到该项目的创作蓝图。
5. 用户启用“创建后生成候选大纲”时，调用现有 `planning` 角色生成原创候选大纲。
6. 候选大纲进入现有查看、编辑、比较、逐项应用、整体应用、放弃和历史恢复流程。

模型输入只包含项目要求、用户确认的可迁移写法、市场建议和用户补充说明。提示明确禁止复用来源作品的人物、设定、关键情节和独特表达。

如果项目创建成功但大纲生成失败，项目和已采纳写法继续保留。页面显示“作品已经创建，可以稍后重试”，并提供前往“作品应用”重新生成的按钮。

## 删除未完成的开书草稿

这里的“草稿”专指 `wizard_sessions` 中尚未确认创建作品的开书向导，不是正文草稿。

### 后端规则

- 新增 `DELETE /api/wizards/{wizard_id}`。
- `WizardService.delete()` 只允许删除没有 `project_id` 且状态不是 `completed` 的向导。
- 删除向导记录时，SQLite 外键级联删除该向导的访谈消息。
- 已经创建项目的向导返回冲突错误，项目、资料、正文和运行历史保持不变。
- 找不到草稿时返回中文的“草稿不存在或已经删除”。

删除不需要新表或迁移。它只清理尚未成为项目的临时输入。

### 页面规则

- “继续草稿”旁显示“删除草稿”，没有选中草稿时禁用。
- 点击后显示草稿名称，并说明“只删除这份未完成的开书资料，不会删除任何作品”。
- 删除成功后立即从列表移除；如果正在编辑该草稿，关闭编辑区并恢复“开始创建”状态。
- 删除失败时保留当前表单，并显示原因和可执行的下一步。

## 与安全定向返修的关系

任务式工作台不改变返修判断。它读取安全返修提供的状态，并把主按钮指向正确动作：

- 本地硬性问题未通过：显示“先处理这些问题”，不允许终审。
- 模型正在生成局部修改：持续显示处理到第几项。
- 修改需要用户确认：显示“查看修改前后”。
- 低风险修改通过：显示“局部复核完成”。
- 结构、开头、高潮、结尾或剧情事实发生变化：显示“需要全文复核”及普通中文原因。
- 失败或中断：显示已经保留的内容和“从失败项继续”。

首页只展示最多三项问题。完整问题、修改前后、影响位置和检查结果放在稿件质量区域，默认折叠详情，避免首页再次堆满模块。

## 错误处理

- 页面调用期间禁用对应按钮，防止重复创建向导、项目或运行任务。
- 所有异步操作显示“正在准备、正在处理、完成、失败”之一，不使用一直运动但已经结束的进度条。
- 后端英文异常经过现有错误翻译后再显示。页面不能直接显示内部枚举、模型原始报错或路径。
- 刷新页面后，未完成向导可以继续；失败的候选大纲生成可以从作品应用重试；安全返修从检查点继续。

## 测试与验收

自动化测试必须覆盖：

1. 侧栏只有四个主分组，旧页面仍可通过组内入口访问并正确高亮。
2. 首页根据无作品、未初始化、运行中、待返修和可发布状态显示正确的唯一主操作。
3. 首页最多显示三项关键问题，详细报告仍可访问。
4. 多选参考资料后只带入用户确认的写法，不发送参考原文。
5. 任一所选资料缺少确认写法时不创建项目，并保留选择状态和明确下一步。
6. 超过 12 条写法时要求用户选择，不静默截断。
7. 候选大纲生成失败不删除已经创建的项目，并可重新生成。
8. 未完成向导可以删除，关联访谈消息同步删除。
9. 已完成或已经关联项目的向导不能删除。
10. 删除当前草稿后页面回到创建状态，其他草稿和作品不受影响。
11. 桌面和移动端没有文字溢出、按钮偏移、内容重叠或动态状态引起的布局跳动。
12. 全部用户可见新增文案为易懂中文。

自动化测试不得调用付费模型。大纲生成测试使用本地假模型返回；浏览器验证只验证界面和本地接口。

## 回退

旧视图、旧向导、自主构思入口、单篇参考资料入口、现有大纲编辑器和原工作流全部保留。若任务式首页判断异常，用户仍可从组内入口进入原页面。删除草稿没有数据迁移；撤回 API 和按钮即可恢复旧行为。安全定向返修按其独立设计保留原全文终审路径作为兼容回退。
