# 范文笔感学习设计

## 目标

允许用户为当前作品上传 TXT/Markdown 范文或粘贴文本，提炼可描述的写作特征，并让正文生成和润色自动使用这些特征。

## 方案

- 浏览器使用 `FileReader` 读取 `.txt`/`.md`，以 JSON 发送，避免新增 multipart 依赖。
- 服务端限制范文长度，原文保存为项目内 `style-samples/reference.txt`。
- 现有 planning 角色仅调用一次，返回严格 JSON，描述节奏、句式、对白、视角、动作神态、用词和禁用倾向。
- 分析成功后把结果写入 `style-profile.md` 的受控区块；失败时不覆盖旧档案。
- 生成和润色继续通过现有 `ensure_style_profile()` 自动读取，无需增加每章模型调用。
- 提示禁止复刻原句、专名、情节和作者标志性表达，只学习一般性风格特征。

## 界面

工作台增加“范文笔感”区域，支持文件选择、粘贴、分析、查看当前档案和删除。删除只移除范文学习区块及原始范文，不破坏作品基础风格档案。

## 验证

覆盖文本校验、成功写入、失败保留、删除恢复基础档案和 API 行为；完整测试通过后重启本地服务。
