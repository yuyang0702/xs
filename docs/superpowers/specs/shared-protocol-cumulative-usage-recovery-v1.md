# Shared protocol usage and successor authorization

The accounting domain is a closed protocol contract. Anthropic SDK commit `62de60b27d04f0927a0ccf0f2610597fafcfab6a` defines message start seeding and cumulative message-delta replacement. The shared reducer owns four numeric counters: input, cache creation input, cache read input and output. It validates integer values, retains omitted optional fields, ignores unsupported billing extensions and computes canonical total input only after fieldwise merge. Generated business content retains its existing validators and authority path.

`ProviderReportedActualUsageV1` retains its exact byte-hash, source-topology, count and receipt-hash format. Previously valid ordinary receipts remain verifiable. The historical conflicting capture now yields 89,255/9; its new replay receipt does not mutate or re-sign the old failed campaign. Exact raw bytes remain outside Git.

`FullShortSharedProtocolSafeUsageRecoveryAndSuccessorExecutionAuthorizationV1` inherits the existing outer campaign's strict routes, fixtures, budgets, zero usage, nested runtime authorization and dependency checks. Its own schema and authorization source identify the fresh Master. Its required `shared_protocol_usage_recovery` binds authoritative usage evidence, historical raw SHA, exact replay, disposition, request-zero-diff and response-regression proofs. No old authority is migrated into an unused authority. Canonical validation/rendering is idempotent for both schemas; existing old bytes remain unchanged.

The selected disposition is `FRESH_REPLACEMENT_REQUIRED`, due to missing historical HTTP-status metadata and a concrete 3xx ambiguity in the old dispatcher. It authorizes eight fresh single-dispatch cases under a new outer hash. Existing case labels identify the unchanged request families; newly generated nonces and the new authorization scope distinguish the successor. No historical nonce or failed state is reset.

`ProbeProtocolCaptureMetadataV1` is an additive, external, per-case HMAC envelope. Before response conversion it binds HTTP status, content type, encoding, transport completeness, exact entity length/hash, request hash, route fingerprint, frozen execution head, outer authorization and the already reserved attempt nonce. It stores no request body, authentication header, model output text or key. Existing campaign state records continue to restore without a schema migration; the source label for a partially known debit now distinguishes retained known usage plus conservative output reserve. Repeated restoration does not redispatch consumed cases.

Workload comparisons use local probe estimates against local physical request estimates. Provider usage drives realized accounting independently. Ambiguous output retains at least the full cap and any known larger output; input retains the greater of its estimate and known Provider value. The immutable historical 30,458/2,974 debit is reported as an estimate/reserve. It is never relabeled as the recovered 89,255/9 measurement.

Rollback before execution freeze reverts only the successor commits. After freeze the campaign only writes external evidence, consumes at most its authorized probe set and one Full Short, and seals the first terminal failure without automatic restart.
